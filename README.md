# 📊 Inventory Optimization & Stockout Risk Analysis

## 📌 Project Overview

This project analyzes inventory data to identify **stock shortages, stockout risks, inventory coverage, reorder requirements, and supplier-related factors**.

The analysis was performed using **Microsoft Excel**, including data cleaning, calculated fields, pivot tables, analysis, and an interactive dashboard.

## 🎯 Business Objective

The objective is to help identify inventory items that require attention and support better **replenishment and stock management decisions**.

Key questions addressed:

* Which products face inventory shortages?
* How much inventory needs to be reordered?
* Which stores have higher stockout risk?
* How many days of inventory are currently available?
* How does supplier reliability relate to inventory requirements?
* Which inventory areas should be prioritized for replenishment?

The project includes:

* Data cleaning and preparation

* Store-wise inventory analysis
* Store-wise stockout risk analysis

* Interactive dashboard creation

## 📈 Key Insights

* **64.9%** of records face an inventory shortage.
* **24.6%** of records are at stockout risk.
* Total reorder requirement is **742,799 units**, exceeding current stock of **700,807 units**.
* Average inventory coverage is only **7.03 days**.
* Stockout risk varies significantly across stores.
* Supplier reliability alone does not strongly determine reorder demand.

## 💡 Recommendations

1. Prioritize inventory with both shortage and high stockout risk.
2. Focus replenishment efforts on high-risk stores.
3. Use lead-time demand when planning reorder quantities.
4. Monitor low inventory coverage regularly.
5. Consider demand, lead time, and supplier reliability together when making replenishment decisions.
